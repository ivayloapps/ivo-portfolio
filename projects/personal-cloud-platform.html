PROJECT CASE STUDY

Personal Cloud Platform

A production-style SRE / Platform Engineering project that takes a FastAPI service through PostgreSQL persistence, containers, Kubernetes, Infrastructure as Code, observability, security validation and an automated v1.0.0 release.

View repository ↗ v1.0.0 release ↗

01 / WHY

Why I built it.

The project gives me a personal environment where I can build infrastructure and platform concepts from scratch, outside of enterprise systems.

The goal is not to create a tutorial-only repository. Each phase should produce a working milestone that demonstrates how application code, automation, containers, orchestration, infrastructure and observability fit together.

03 / IMPLEMENTATION

What v1.0.0 delivers.

Application & data

FastAPI service with PostgreSQL-backed CRUD, health/readiness endpoints and Alembic migrations.

Containers & Kubernetes

Docker runtime, Kustomize manifests, kind integration testing, persistent storage and NetworkPolicies.

IaC & CI/CD

Terraform modules validated in CI, plus automated Python, Docker and Kubernetes quality gates. Terraform remains validation-only with no automatic cloud deployment.

Observability & release security

Prometheus metrics, Grafana dashboards, Trivy scanning, CycloneDX SBOM, GHCR publishing and automated GitHub releases.
