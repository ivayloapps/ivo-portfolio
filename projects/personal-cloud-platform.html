PROJECT CASE STUDY

Personal Cloud Platform

A hands-on SRE / Platform Engineering project designed to evolve from a simple API into a containerized, orchestrated, automated and observable cloud-native platform.

View repository ↗ Current roadmap →

01 / WHY

Why I built it.

The project gives me a personal environment where I can build infrastructure and platform concepts from scratch, outside of enterprise systems.

The goal is not to create a tutorial-only repository. Each phase should produce a working milestone that demonstrates how application code, automation, containers, orchestration, infrastructure and observability fit together.
